# Fictional Demo Refund Guidance

DEMO ONLY: This invented text is for software testing and is not an actual
company policy.

For this fictional example, a customer may request a return within 30 days of
delivery when an item is unused and in its original packaging. A refund is
reviewed after the returned item is received. This example does not promise a
refund for every return.

For this fictional example, damaged-item questions should include the order
reference and a description of the damage. Do not send payment-card details.
